# Install GG Counter and use it offline

This guide shows you how to install GG Counter so it opens like an app, and how it behaves without internet.

## Install on Android or a computer, in Chrome or Edge

1. Open [GG Counter](https://simeontsvetanov.github.io/GG-counter/) in Chrome or Edge.
2. Go to **Menu** > **Install app**.
3. Confirm the install in your browser's prompt.

If your browser offers the install, GG Counter also shows a banner with **Install app** and **Dismiss**. You can select **Install app** there. On a computer, the install icon in the address bar works too.

If your browser doesn't offer the install, **Install app** opens **Help** at the steps for your device. When GG Counter is installed, the menu item reads **Installed ✓**.

## Install on iPhone or iPad

1. Open GG Counter in Safari.
2. Select **Share**, the square with an arrow.
3. Select **Add to Home Screen**.
4. Keep **Open as Web App** turned on.
5. Select **Add**.

GG Counter appears on your Home Screen and opens in its own window.

## Use GG Counter offline

Open GG Counter once while you're online. GG Counter shows **Ready to work offline ✓** when the offline copy is complete. After that, it works without internet, whether you installed it or not.

When you're offline, GG Counter shows "You are offline. Everything keeps working, and your game is saved on this device." Adding players, changing scores, the leaderboard, **Help**, **Settings**, and export and import all work offline, and so do the policy pages. Sharing to another app needs that app's own connection to send the message. Opening a GitHub issue from **Report a problem** needs internet.

## Update GG Counter

When a later version is ready, GG Counter shows **New version available** with **Reload**. Select **Reload** when it suits you. GG Counter never reloads by itself in the middle of a game, and your game stays saved.
